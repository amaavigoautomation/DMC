All 49 HTML pages contain one canonical link and one static JSON-LD graph inside `<head>`, before `</head>`. These tags are available in the initial HTML, including for pages whose visible content is generated by JavaScript.

The homepage uses `/`; other pages use their existing `.html` route. Each page has its own canonical. Dubai and UAE remain separate pages with distinct content. No unverified external domain is used.

- Software-focused pages: SoftwareApplication describing DMC24, with BusinessApplication category.
- Company pages: AboutPage.

No fabricated ratings, reviews, authors, dates, business addresses or prices. LocalBusiness is not used for this software website. SoftwareApplication describes the product; it is not a claim of eligibility for Google's software rich results, which have additional requirements.

## Update procedure

1. Maintain titles/descriptions/headings in `SEO_PAGE_METADATA.json` and the corresponding page content.
2. Maintain domain and page-type exceptions in `SEO_SITE_CONFIG.json`.
3. Run `python scripts/generate-seo-structure.py` from the repository root.
4. Check `SEO_SCHEMA_MANIFEST.json`, JSON syntax, graph references and content agreement before publishing.

The script reads FAQ answers directly from the HTML and fails if the expected FAQ markup is missing. Regenerate whenever FAQ content changes. The generator is a maintenance utility, not a new build system or browser dependency.

For a custom-domain launch, change `canonical_origin`, regenerate and deploy to that domain before requesting indexing. Current owner-private access was preserved: these tags do not make private pages crawlable. Search appearance is not guaranteed. This work does not change sharing, robots directives, redirects or sitemap configuration.
