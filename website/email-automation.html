Microsoft 365 setup instructions
  1. Ask your Microsoft 365 administrator to register a single-tenant application in Microsoft Entra ID.
  2. Authorise Microsoft Graph application mail sending for the chosen mailbox. Use Exchange Online application RBAC to scope access to this mailbox; do not leave an additional unscoped permission grant that widens access.
  3. Copy the tenant ID and application ID here. Create a client secret and enter its value in the password field. Do not enter your mailbox password.
  4. Enter the sender mailbox and reply-to address, then save. Send a test to an address you control and check its inbox or junk folder.
  5. Review the templates and country benefits, then enable automatic responses and save again. Set a reminder in your IT process to rotate the Microsoft client secret before it expires.

Microsoft application authentication guidance ↗ · Mailbox access scoping ↗

Sending uses Microsoft Graph over HTTPS. No SMTP password is required. Your sender domain’s SPF, DKIM and DMARC should be configured by your Microsoft 365 administrator.
