    Individual login — proposed flow

    Simulation only

    No invitation is sent and no reset link is generated.

    1. Super Admin creates the user and assigns module rights.
    2. The user receives a time-limited password-setup invitation.
    3. They set their own password and sign in using their email.
    4. They see only permitted modules; server checks protect direct page and API access.

    Planned account controls: password reset, session expiry and immediate access revocation when an account is disabled. Website hosting access remains a separate requirement.
